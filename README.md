Para navegar, toque no lado direito ou deslize para avançar e toque no lado esquerdo para voltar. No teclado: setas, **M** para o menu, **N** para as notas e **F** para tela cheia.

As fontes e o histórico de versões ficam no repositório privado `jads-Marcelino/Meridiano`. Este repositório recebe só os arquivos prontos.

**Assessments:** entre com a conta do Meridiano Studio. Cada assessment enviado (PDF, Word, texto, link ou notas coladas) é lido contra a guía e vira uma cópia preenchida. Resultados e arquivos ficam privados no Supabase (tabela `assessments`, bucket privado `assessments`), não neste repositório público.
